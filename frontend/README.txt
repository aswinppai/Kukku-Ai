KUKKO — POLISHED BUILD

This version improves the existing Kukko procedural renderer without Blender,
Three.js, npm, or external libraries.

Files:
- manifest.json
- content.js
- style.css

Install:
1. Open Firefox -> about:debugging
2. This Firefox -> Load Temporary Add-on
3. Select manifest.json

The companion now appears bottom-right with a glass panel, status badge,
speech bubble, action buttons, smoother sizing and better interaction.
